# 必殺技カットイン演出 ＋ 演出スピード設定（『黒猫のウィズ』研究から採用）

## 背景（調査結果）
『魔法使いと黒猫のウィズ』(コロプラ)では、クイズに正解すると精霊が攻撃する。正解数が溜まると使える
「スペシャルスキル」は、カットイン(キャラ絵＋技名＋セリフ)→攻撃エフェクトが一体になって流れ、これが好評。
一方でユーザーの不満は「演出が長い／固定で飛ばせない／連撃数に関係なく時間が同じ」。
→ 数学ラボ3では「気持ちいい必殺技カットイン」を作り、同時に「演出スピード（ふつう/はやい/オフ）」を必ず付ける。
  授業では何十回も戦うので、飛ばせない長い演出は害になる。

## 作るもの
1. **必殺技カットイン** `src/components/UltimateCutIn.jsx`（＋CSS）
   - 必殺技を使う瞬間に再生（TurnBattle.jsx の ultimate 発動時。Battle.jsx に必殺技相当があれば同様）。
   - 構成: 背景が暗転 → 斜めの光の帯が左から走る → 主人公の絵(HeroImg等、既存の画像を使う)が帯の中にスライドイン →
     必殺技名(大きく、縁取り・グラデ)＋一言セリフ(「いくよ！」等、技ごとに短い)→ 集中線・放射光・光の粒 →
     フラッシュして既存の攻撃球エフェクト(AttackOrbFx, strong)へつなぐ。長さは「ふつう」で約1.3秒。
   - タップ/クリックで即スキップできる（スキップしても攻撃の結果・ダメージ処理は必ず実行される）。
   - 必殺技名・アイコンは既存データ（ultimateDef.name / icon）を使う。
2. **演出スピード設定** 「演出: ふつう / はやい / オフ」
   - バトル画面の目立たないところ（例: 右上の小さな切替ボタン）で切替。localStorage に保存(try/catch)。キー名は `mathApp3_fxSpeed`。
   - ふつう=全演出、はやい=カットインは0.5秒に短縮・攻撃球も約半分の時間、オフ=カットイン無し・球は出さず短いフラッシュとダメージ数字のみ。
   - 既存の AttackOrbFx と、勝利バナー等の演出にも速度設定を反映する（reduced-motion 設定時は自動で「オフ」相当）。
   - AttackOrbFx.jsx が持つ 830ms などの固定タイミングを、速度係数を掛ける形にする。
3. 共通で使えるように `src/engine/fxSpeed.js`（getFxSpeed / setFxSpeed / 係数を返す関数）を作る。

## 守ること
- 編集は数学ラボ3フォルダ内のみ。他のフォルダは読むだけ。ブランチ design-v2 上、コミット不要。
- **触らないファイル**: src/third/ 配下、scripts/sim-gauge-battle.mjs、src/screens/Home.jsx（別作業が進行中）。
- ダメージ計算・SP消費・ターン進行などのロジックは変えない。演出の再生とスキップに関わる最小限の変更にとどめる。
- 連打・画面遷移・アンマウントで演出が残らない（タイマー/クラスの後始末）。
- 小学生〜中学生向け。文字は大きく読みやすく。軽量に。
- 最後に npm run build を通し、docs/DESIGN_CHANGELOG_CUTIN.md に変更点と使い方を日本語で記載。
