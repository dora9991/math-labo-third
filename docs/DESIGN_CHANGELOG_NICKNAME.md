# 仲間のニックネーム（2026-10-13）

生徒の要望「自分のキャラクターにニックネームをつけたい」への対応。
※ 「プレイヤー自身の呼び名」（🎨キャラクター画面）は前からある別の機能。ここで作ったのは **ガチャで集めた仲間（5体のパーティなど）ごとのニックネーム**。

## しくみ
- 保存：`state.owned[id].nick`（文字列。無ければ項目ごと無し）。**SQL変更なし**（状態のJSONに載るだけ）。
- 変更：サーバーの新しい操作 `set_nick { id, nick }`（`core.js` の `setNick`）。持っている子だけ。空文字／空白だけなら消す。
- 整え方（`src/third/nick.js` の `cleanNick`。サーバーも画面も同じ規則）：前後の空白を取る／改行・制御文字・ゼロ幅文字は空白に／連続する空白は1つ／**8文字まで**（見た目1文字ずつ。絵文字も1文字）。
- 壊れた保存（長すぎ・空白だけ）は読み込み時にも整える（`normalizeThirdState`）。
- 限界突破・合成の強化先・編成の入れ替えでは消えない。**合成の素材にして手放すと、その子といっしょに消える**（再び仲間にしたときは名前なし）。
- ローカル（開発）モードも同じ処理で動く。ゲスト（ログインなし）は、その場かぎり（他の保存と同じ）。

## 画面
- ニックネームを変える場所：**キャラの詳細ポップアップ**（パーティ編成・図鑑のキャラをタップ）。持っている子だけ入力欄が出る。「つける」／Enter／「もとの名前にもどす」。
- 出る場所：ポップアップの見出し（元の名前は小さく）／パーティ編成のカードの下（Lvの下）／図鑑の名前／合成（強化先の名前・限界突破のお知らせ）／バトル後の経験値メーター／バトル中のスキル確認ダイアログ。
- **バトル中の5体の並びには出さない**（2026-09-18「名前は表示せず絵柄を大きく」の指示を守る）。
- **他の人には見せない**（マルチの部屋・協力バトルのメンバー表示にも出さない）。学校で使うので、不適切な名前が他の子に見えないように。見せたくなったら、部屋の `party` に `nick` を載せるだけで広げられる（そのときは先生が見られる仕組みも一緒に）。

## 公開の順番
新しい操作が増えるので、**先に関数を再登録 → あとでサイト公開**（協力バトルと同じ順番。同じ1回の再登録でまとめて入る）。古い関数のままサイトだけ出すと、「つける」が「うまくいかなかったよ」になる（それ以外は動く）。
