# 数学ラボ3 デザイン変更履歴

実施日: 2026-09-20

## コンセプト

「数学の研究施設が浮かぶ星空」を軸に、数式・グリッド・発光する計器の要素を残したまま、深い藍色、シアン、バイオレット、金色で統一しました。学習中の文字と解答欄は明るい面にして、背景演出より読みやすさを優先しています。

## 全画面

- 色、角丸、罫線、影、パネルの共通トークンを追加しました。
- 星空の光、数学グリッド、ガラス質のカードを全メニュー・単元選択・結果・教師モードに適用しました。
- ヘッダー、戻る操作、ステータスチップ、カード、既存のインラインボタンを同じ視覚言語に揃えました。
- 小さな画面でも読みやすい余白と文字サイズに調整し、操作ボタンの最小高を44pxに設定しました。
- キーボード操作時のフォーカスリングと、OSの「視差効果を減らす」設定への対応を追加しました。

## 学習・バトル画面

- 問題カードと結果カードは白〜淡青の高コントラスト面に変更し、問題文・選択肢・入力欄の判読性を強化しました。
- バトルはレトロRPGの構造を保ったまま、天文台のような発光グリッド背景、ガラスパネル、光輪ステージへ刷新しました。
- HPバー、選択肢、SP表示、正解演出を青紫・シアンの発光表現に統一しました。

## 起動画面・名称

- CSSだけで星雲、星、軌道リングを構成した起動画面・タイトル背景を追加しました（画像ファイルへの依存なし）。
- ヘッダー、開始画面、タイトル、ログイン画面の表示名を「数学ラボ3」に統一しました。

## 検証

- `npm run build` を実行し、正常終了を確認しました。
- Viteの既存バンドルサイズ警告は出ますが、ビルドエラーはありません。
