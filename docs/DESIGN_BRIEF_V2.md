# 数学ラボ3 デザイン刷新 第2弾（自由裁量版）

## 絶対ルール
- 編集してよいのはこのフォルダ（数学ラボ3）のみ。../数学ラボ2 ../math-dialogue ../math-world ../math-labo2 は読むだけで編集禁止。
- 学習ロジック・問題データ・採点・保存キー・認証・Supabase連携は変えない。
  バトルのルール（HP、ターン、SP、スキル効果の数値）も変えない。変えてよいのは「見た目・配置・演出」。
- 作業は git ブランチ design-v2 上。コミットはしなくてよい（私がする）。

## 目標
「叡智のアストラ」の世界観（星空に浮かぶ学園・天文台・発光する数式・金とシアンとバイオレット）を維持しつつ、
自由に大胆にデザインを変えて、前回(第1弾)より一段上の完成度にする。
「数式・機械的な雰囲気」も残す（グリッド、計器、ホログラム、回路のような線）。

## 自由に変えてよい範囲
1. **背景**: 各画面の背景（ホーム/単元選択/バトル/結果/教師モード）。docs/reference-astra/astral/ の3枚の画像を
   public/ に取り込んで使ってよい。足りなければ CSS/SVG で作る、または画像生成が使えるなら生成。
2. **ボタン**: 形・質感・光り方・押した時の動き・SEなしの視覚フィードバック。
3. **ボタン配置・画面レイアウト**: ホームのメニュー構成、バトル画面のHP/SP/コマンド/問題の並べ方を、
   iPhone横画面・iPad・PCで使いやすく再設計してよい（機能は全て残す。ボタンを消さない）。
4. **敵キャラのデザイン**: 今の見た目（絵文字など）を、キャラらしい見せ方に。
   docs/reference-monsters/*.webp（math-worldの魔物画像157枚）と docs/reference-astra/monster-sheet-*.png を
   参考/素材にして、public/ に取り込み、敵の種類・強さ（雑魚/ボス）に応じて出し分ける。
   出現アニメ（浮遊・呼吸・ダメージ揺れ・撃破の消え方）も付ける。
5. **攻撃エフェクト・必殺技エフェクト**: プレイヤーの攻撃、敵の攻撃、ダメージ数字、クリティカル、
   必殺技（スキル発動）の演出を派手で気持ちよく。参考: docs/reference-astra/math-world-BattleFX.jsx.txt
   （数字とシンボルが飛ぶ、光のリング、衝撃波など）。CSSアニメ/SVG/canvasで実装。
6. 文字（フォント・サイズ・グラデ）、アイコン、効果音の見た目側の連動。

## 品質基準
- 小中学生が使う: 文字は大きく読みやすく、タップ領域44px以上、問題文と選択肢は高コントラスト。
- 端末: iPhone横画面(844x390)、iPad、PC で崩れない。prefers-reduced-motion 対応。
- 重すぎない（低スペック端末でもカクつかない、画像は webp/圧縮）。

## 完了条件
1. `npm run build` が通る。
2. 変更点を docs/DESIGN_CHANGELOG_V2.md に日本語で要約（何を・どこを・どう変えたか、追加した素材の出所）。
3. 変えなかったものと、迷った点・要判断点も書く。
