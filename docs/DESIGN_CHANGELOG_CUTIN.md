# 必殺技カットイン・演出速度設定 変更記録

## 変更内容

- `UltimateCutIn` を追加し、必殺技で「暗転 → 斜めの光帯 → 主人公立ち絵 → 技名・セリフ・集中線 → 攻撃球」の順に再生するようにした。技名・アイコン・色は既存の必殺技データを利用する。
- `TurnBattle` と従来の `Battle` の両方で、カットインの完了後に既存の強い `AttackOrbFx` を起動するよう接続した。カットインをタップ／クリックすると即座に着弾へ進み、ダメージ、SP消費、ターン進行の計算は変えない。
- バトル右上に「演出: ふつう / はやい / オフ」を追加した。選択値は `localStorage` の `mathApp3_fxSpeed` に保存する。
- `ふつう` はカットイン約1.3秒、`はやい` は約0.5秒・攻撃球は半分の時間、`オフ` はカットインと球を省略して短いフラッシュとダメージ表示だけにする。勝利バナー等にも速度を反映する。
- OSの「視差効果を減らす」が有効な場合は自動的にオフ相当になる。`AttackOrbFx` のタイマーとCSSアニメーションは同じ速度係数を使い、アンマウント時にはタイマーを解除する。

## 使い方

1. バトル画面の右上で演出速度を選ぶ（次回以降も保存される）。
2. 必殺技を使うとカットインが出る。途中で画面をタップ／クリックすると、演出だけをスキップして攻撃結果は必ず反映される。
