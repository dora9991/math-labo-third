# 数学ラボ3 デザイン変更履歴 — 第2弾

実施日: 2026-09-20

## ねらい

第1弾の「星空の学習研究施設」を土台に、アストラの空中学園・天文台が実際に見える画面へ進めました。背景を単なる飾りにせず、ホログラム、測定器、回路グリッド、金色の発光を重ね、問題と選択肢だけは常に読み取りやすい面として残しています。

## 変更したもの

### 全体・ホーム・メニュー

- `src/styles/theme.css` に第2弾の上書きスタイルを追加しました。
- ホーム、単元選択、結果、記録、教師モードを含む通常画面の背景に、空中学園の画像と濃い藍色の可読性ベールを重ねました。固定グリッドと斜めの回路線で、画面をまたいだ世界観の連続性を持たせています。
- ヘッダーに `ASTRA OBSERVATORY` の計器ラベルを加え、ガラスカード、単元カード、モードカードにはハイライト、光の輪、進行方向マークを追加しました。既存ボタンの機能・文言・順序は変更していません。
- 起動画面の空は「浮遊する天空都市」の画像に置き換え、既存の星・軌道リング演出を重ねました。

### バトル

- `src/styles/battle.css` に天文台デッキ用の第2弾スタイルを追加しました。観測所の背景、星、光る地平線、透視グリッドのステージ、モンスター背後の回転ホログラムを組み合わせています。
- 敵HPの先端発光、モンスター足元の光、ダメージ数字の金・ピンクの立体表示、選択肢の走査光、タップ時の沈み込みを追加しました。既存の浮遊、被弾、攻撃、撃破、必殺技カットイン、正解リングの状態演出は維持・強調しています。
- 横幅760px以上、または横向き端末では、左に敵・プレイヤー・ステージ、右にSP・問題・行動を置くコンソール型2カラムにしました。iPhone横（高さ430px程度）では各パネルと舞台を圧縮し、問題と44px以上の操作領域を優先します。
- `prefers-reduced-motion` 時は追加したホログラム回転も停止します。

## 追加した素材と出所

- `public/astral/title-sky-kingdom.png` — `docs/reference-astra/astral/title-sky-kingdom.png` から取り込み。起動画面用。
- `public/astral/menu-academy.png` — `docs/reference-astra/astral/menu-academy.png` から取り込み。通常メニュー画面用。
- `public/astral/battle-observatory.png` — `docs/reference-astra/astral/battle-observatory.png` から取り込み。バトル背景用。
- 敵キャラクターは第1弾で導入済みの `src/assets/monsters/full/*.webp` / `small/*.webp` を継続使用し、今回のホログラム枠と発光ステージで見せ方を強化しました。新規の外部素材・生成画像は追加していません。

## 変えなかったもの

- 学習ロジック、問題データ、採点、保存キー、認証、Supabase連携は変更していません。
- HP、ターン、SP、スキル効果量を含むバトルルールは変更していません。
- 既存のすべての操作・ボタンは残しており、配置と視覚表現のみを変更しています。

## 迷った点・要判断点

- 背景画像は各2.5〜2.9MBです。画質を優先してそのまま配置しましたが、モバイル回線を最優先する場合は、同じ構図のAVIFまたは縮小WebPを別途用意して `image-set()` に切り替える余地があります。
- バトルの横画面2カラムはCSSのみで既存DOMを再配置しています。実機で長い問題文・補助入力・計算スペースを開いた際の使い心地について、学校で主に使うiPad機種で最終確認すると安心です。

## 検証

- `npm run build` を実行し、Vite production build が正常終了しました。
- 既存のbundleサイズ警告（`index` chunkが500kB超）は表示されますが、ビルドエラーではなく今回の背景画像は `public/` 配下の静的配信です。
