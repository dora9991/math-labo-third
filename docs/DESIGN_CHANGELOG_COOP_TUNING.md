# 協力バトルの調整：経験値を増やす＋敵をもう少し強く（2026-10-14）

生徒の声：「経験値がなかなか手に入らない」。kazu：「マルチの敵はもう少し強くしてもいいかも」「2回目クリア以降は経験値は減る設定だったかな？うまく調整して」。

## 経験値
**2回目以降は減る設定でした**（初回 35%・2回目以降 10%・1日3回まで）。2回目以降は1体あたり 8〜95 しか入らず、1日3回で頭打ちだったので、周回しても手応えが無かった。そこで引き上げ（`raid.js` の `COOP`）：

| | 前 | 今 |
|---|---|---|
| 初回（その章の最後の小単元の初回経験値に対する割合） | 35% | **80%** |
| 2回目以降 | 10% | **30%** |
| 2回目以降で経験値がもらえる回数 | 1日3回 | **1日5回** |

1体あたりの経験値（本人のいまのパーティ5体に1体ずつ。5体とも同じ量）：

| ステージ | 初回 前→今 | 2回目以降 前→今 | 1日の周回の上限（今） |
|---|---|---|---|
| 1話（中1・1章） | 27 → **62** | 8 → **23** | 115 |
| 7話（中1・7章） | 209 → **477** | 60 → **179** | 895 |
| 8話（中2・1章） | 69 → **158** | 20 → **59** | 295 |
| 13話（中2・6章） | 334 → **763** | 95 → **286** | 1,430 |
| 21話（中3・8章） | 191 → **436** | 55 → **164** | 820 |

- 目安：レベル10まで合計 1,620／20まで 7,370／30まで 20,870。
- それでも一人用より少ない：一人用の小単元は 2回目以降でも「雑魚ぶん全額＋ボスぶん30%」で1日10回（例：7章の最後の小単元で1日あたり最大 約4,300／体）。協力バトルの1日の上限（895）はその約2割＝「勉強して経験値をためる」流れは変えない。
- 変えていないこと：正解5問未満の人にはごほうびなし（ただ乗り防止）／負けたときは経験値なし／メダル・クリスタル・称号の仕組み。
- 画面：2回目以降の回数を使い切ったときの文言に回数（5回）を出すようにした。

## 敵の強さ（`raidBattle.js` の `RB`）
スキル（PR #5）を入れたあとの勝率は、普通の子だけのチームで 50／23／40／81／93%（ステージ1／6／11／16／21）と、後半が簡単すぎた。「もう少し強く」に合わせて、**後半を中心に**強くした（序盤・中盤は少しだけ）。

| 値 | 前 → 後 |
|---|---|
| `RB.bossHp` | 0.52 → 0.54 |
| `RB.bossDmgFrac` | 0.10 → 0.102 |
| 後半の上乗せ（新設）`lateFrom`／`lateHp`／`lateDmg` | なし → 全体の4割より後ろで、最後のステージ（21話）に向けて HP +20%・攻撃 +7%（なめらかに増える） |

勝率（3人・各80回。ステージ1／6／11／16／21）：
- 得意な子ばかり：96／89／96／100／100% → 93／74／90／100／100%
- 混合（いろいろな子）：93／60／75／100／100% → 83／56／74／98／74%
- 普通の子ばかり：50／23／40／81／93% → 51／10／15／69／55%
- 苦手な子ばかり：0%（変わらず）
- 2人：混合 90／78／92%（1・11・21話）、5人：混合 82／52／94%。
- 1ステージ 約5〜8分（変わらず）。
- 注意：シミュレーションの「各ステージのパーティ」は想定（序盤は初期の子、中盤はN・R、後半はSR・UR）で、実際の教室とは違う。実際に遊んでもらって、強すぎる・弱すぎるときは `RB` の数字だけで直せる（`node scripts/sim-raid-battle.mjs --set "RB.lateHp=0.3"` で試せる）。
