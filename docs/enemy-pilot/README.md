# 敵デザイン・パイロット

ASTRA ACADEMY の敵を、味方のデフォルメ調に対する「少し写実的で重厚なダークファンタジー」として再設計するための10体の見本です。全画像は 512×512 の透過 WebP と、96×96 の透過 WebP を収録しています。

## 絵柄ガイド

- **質感**: 黒曜石、深藍の装甲、古びた金、発光する淡シアンの結晶を、塗り込み過ぎずゲーム用に読める面で表現する。
- **光**: 下方から淡いシアンのリム光。背後には人物・魔獣の輪郭を妨げない小さな魔法陣の後光を置く。
- **シルエット**: 96pxでも種別を識別できるよう、四角い人形／天秤獣／結晶柱／三角甲虫／石像／鳥／ドーム亀竜／竜王を輪郭から区別する。
- **数学モチーフ**: 数、天秤、結晶、グラフ、図形、天文器具を構造・装飾として組み込む。読み取れる数式・文字・数字は画像内に置かない。
- **安全性**: 血、グロテスクな損傷、残酷な武器表現は使わない。威厳と不穏さは光・材質・姿勢でつくる。

## 生成・透過処理

生成は組み込みの画像生成機能を使用。各プロンプトには「透明背景」「全身」「約6%の余白」「正面〜3/4」「床影なし」「文字・ロゴ・透かしなし」を指定し、共通色を黒曜石・深藍・金・淡シアンに固定しました。個体固有のモチーフだけを変え、ボスは輪郭の系統も重複させていません。

生成PNGのアルファ境界を取得し、被写体と後光を透明領域のまま最大450pxに収め、512px角の透明キャンバス中央へ配置して lossless WebP 化しました。同じアルファ付き画像を96pxへ縮小してサムネイルを作成しています。検査では20ファイルすべてに透明アルファを確認済みです。前景の半透明アンチエイリアスを保持しているため、単色背景由来の縁フリンジはありません。

## 課題・次回確認

- 512px実装時はゲーム背景ごとに後光の明るさと縁の見え方を確認する。
- 96pxでは細部が消えるため、量産時は「輪郭・目の発光・主モチーフ」を優先し、細い装飾を増やさない。
- 生成物の文字混入、余白不足、同一シルエット化をレビューゲートで機械・目視の両方で弾く。
- 全量産前に、この10体を実戦UIに仮差しして敵・味方・背景とのコントラストを確認する。
