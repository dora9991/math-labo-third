## (2) パーティ編成のドラッグ表示

原因は `.mw-fantasy-screen` 配下の祖先にある transform 系の表示コンテキストで、`position: fixed` のゴーストが viewport ではなく祖先基準になり得たこと。

- ゴーストを `createPortal(..., document.body)` で body 直下に描画した。
- `clientX/clientY` と `translate(-50%,-50%)` を使い、ポインタ中心に追従する。
- 10px を超えて初めてゴーストを出すため、タップ開始時のちらつきを除去した。
- `pointercancel` も片付け、既存の控え→編成・編成→控えのドロップ判定は変更していない。`touch-action: none` は既存のまま。

変更箇所: [PartyFormation.jsx](../src/third/screens/PartyFormation.jsx) の12–13、76–153、214–220行。ゴーストの既存CSS（中心合わせ）を維持している。

- `GameButton` の sparkle/shine要素を削除し、メインタイル上の星粒疑似要素も削除した。

- 遷移は表示だけで、クリックを待機・キューイングしないため操作不能時間は作らない。
