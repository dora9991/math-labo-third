# 数学ラボ3 デザイン第3弾 — 「ソーシャルゲームの手触り」

## 依頼者からの評価（第2弾へのフィードバック）
「ボタンなどが、デザインが苦手な人がとりあえず作ったようでダサい。もっとソーシャルゲームのような
ワクワクするエフェクトつきの演出と形にしてほしい。」
→ 第2弾は「半透明の角丸四角＋薄い枠線」のWebアプリ風で止まっている。これを根本から作り直す。
  CSSの上書きだけでは足りない。**JSX（マークアップ）を変えてよい。共通部品を新設してよい。**

## 絶対ルール
- 編集してよいのは数学ラボ3フォルダのみ。../数学ラボ2 ../math-dialogue ../math-world ../math-labo2 は読むだけ。
- 学習ロジック・問題データ・採点・保存キー・認証・Supabase連携・バトルの数値ルールは変えない。
  ボタンのonClick等のハンドラ・機能・ボタンの数は維持（消さない）。変えるのは見た目・構造・配置・演出。
- ブランチ design-v2 上で作業。コミット不要。

## 目指す質感（参考: パズドラ、ポケモンマスターズ、FGO、ウマ娘、プロセカ、原神のメニュー）
### ボタン（最重要）
- **立体感**: ベベル（縁取りの明暗）、多層グラデ、下側に厚み（押すとへこむ）、内側ハイライト、金縁/ジェム風の装飾。
- **主要ボタン**（はじめる・戦う・学習サイクル・受け取る）は特別に豪華に: 金の縁取り、光沢の帯が定期的に横切る(shine sweep)、
  ゆっくり脈打つグロー、角の装飾(菱形/星/翼など)、リボン。
- **押した時**: 沈み込み＋光の波紋＋星/数式記号のパーティクルが弾ける。ホバー/フォーカスで明るく。
- **種類の作り分け**: 決定(金/オレンジ)、通常(青紫)、戻る/キャンセル(グレー)、危険(赤)、特別(虹/ホロ)。
- 絵文字アイコンをやめ、SVGアイコンや金縁の円形バッジに置き換えてよい（絵文字は残っても可だが装飾する）。
- 共通コンポーネント（例: src/components/GameButton.jsx）を作り、主要画面へ適用してよい。

### 画面
- **ホーム**: 現在は「白っぽい箱の羅列」でダサい。ゲームのハブ画面にする。
  背景の空中学園イラスト(public/astral/menu-academy.png)がちゃんと見えるようにし、
  メニューは大きなイラスト風タイル（金縁・アイコン・リボン見出し・NEWバッジ・光）、
  通貨/レベルは金属プレート風、先生キャラの吹き出し、バナー風のおしらせ。配置はカルーセル/グリッド等、自由に再設計可。
- **タイトル/開始画面**: 光るロゴ、金縁の豪華なスタートボタン、舞い散る光の粒、シンボル。
- **ダイアログ/ボーナス**: 「ログインボーナス」等のモーダルに、光の放射、リボン、キラキラ、コインが弾ける演出。
- 見出し・数字・ラベル: 縁取り文字、グラデ文字、影、ゲーム風の書体（Google Fontsの利用可: 例 Dela Gothic One, Kaisei Decol,
  Zen Maru Gothic, Cinzel）。

### バトル（ワクワクの中心）
- **コマンドボタン**（攻撃/スキル/アイテム/必殺技）: 大きな立体ボタン、アイコン、クールタイム/SPゲージ連動の光。
  必殺技が使える時は虹色に脈打つ。
- **攻撃エフェクト**: 斬撃ライン、衝撃波リング、ヒットスパーク、ヒットストップ風の一瞬停止、画面シェイク、
  ダメージ数字の跳ね上がり（大きく縁取り、クリティカルは金＋「CRITICAL!」）。
- **必殺技エフェクト**: 全画面カットイン（斜めの帯・キャラ名・技名・集中線・放射光）、背景暗転、エネルギーチャージ、
  巨大な光の一撃、画面フラッシュ。
- **敵の演出**: 登場（せり上がり/ワープ）、待機（呼吸・浮遊）、被弾（白フラッシュ＋揺れ）、撃破（光の粒に分解して消える）。
  ボス登場は専用の演出（警告帯「WARNING」等）。
- **正解/不正解**: 正解は光のリングと星、コンボ表示。不正解は赤い揺れ。
- **勝利/リザルト**: 「VICTORY」バナーが飛び込み、経験値バー、獲得コインが弾ける、金色の紙吹雪。
- 実装はCSSアニメ/SVG/canvas。重い画像に頼らず軽量に（低スペックiPadで60fps近く）。
  素材画像を作れる環境（画像生成）があれば、金属フレーム・ジェム・リボン等の装飾素材を透過webpで作って public/ui/ に置いてよい。

## 品質基準
- 小中学生向け: 文字は大きく、タップ領域44px以上、問題文・選択肢は高コントラストで読みやすいまま。
- iPhone横(844x390)、iPad(1024x768)、PCで崩れない。prefers-reduced-motion では派手な動きを止める。
- 「派手」と「読みやすい」の両立。問題を解く画面は演出で邪魔しない。

## 確認方法
- 開発サーバー: `npm run dev` を使うと認証が有効でログインが必要になる。画面確認用に
  `VITE_SUPABASE_URL= VITE_SUPABASE_ANON_KEY= npm run dev -- --port 5187` とすると認証OFFでホームまで行ける。
  スクリーンショットが撮れる手段（playwright等）があれば使って自己確認する。無理ならビルド確認のみでよい（こちらで確認する）。
