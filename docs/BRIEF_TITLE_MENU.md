# タイトル画面 と メニュー画面 の作り直し（参考画像つき）

参考画像: docs/reference-ui/ref-title.webp（左: タイトル） と docs/reference-ui/ref-menu.png（右: メニュー）。
※ 参考は「構成と雰囲気」のみ。ロゴ・アイコン・文言・素材そのものは真似せず、数学ラボ3のオリジナルにする。

## 依頼者の要望
- **タイトル画面**は参考(左)のようなタイトル文字（金属の刻印のような重厚なロゴ）にする。
  背景は今までのもの（public/astral/title-sky-kingdom.png の空中学園）のままでよい。
- **メニュー画面(ホーム)**は今と雰囲気を変えて、参考(右)のような感じにする。
- **ファンタジー要素をもっと強める**。文字は**ポップすぎない、ちょっと大人な感じ**。

## タイトル画面（src/screens/TitleScreen.jsx ほか）
- ロゴ: 「MATH LABO」を大きく、字間を広く取った端正なセリフ体（例: Cinzel / Cinzel Decorative / Cormorant SC。Google Fonts可）。
  文字は銀〜鋼色のメタル質感（縦グラデ＋細い金属の縁＋うっすら刻印風の陰影＋ゆっくり流れる光沢）。
  その下に「数学ラボ３」を明朝系(Shippori Mincho / Noto Serif JP)で小さめに添え、両脇に細い装飾ライン、
  ロゴの背後に淡く光る魔法陣/円環と数式のうっすらした紋様。丸い枠のカードやパネルは撤去。
- メニュー: 参考(左)のように**枠なしの文字だけ**を縦中央揃えで並べる。
  「はじめる / 遊び方 / キャラ」。淡いシアンの発光文字＋広い字間。選択/ホバーで明るく光り、両脇に小さな菱形/光の記号が出る。
  ボタンの箱・塗りつぶしはやめる。ただしタップ領域は44px以上確保する。
- 既存の機能は全て維持: 隠しコマンド（タイトル文字を5回連続タップ／約1.1秒長押しで管理モード）、BGM開始、音量ボタン。
- 背景の空中学園画像はそのまま。粒子(舞う光)は上品に控えめ。

## メニュー画面（src/screens/Home.jsx ほか）
- 参考(右)の構造をファンタジーに翻案:
  - 上部に、斜めに切った見出しタブ（例:「ASTRA ACADEMY ── 冒険の書」）とヘッダーバー。
  - **斜めに切った平行四辺形のタイル**（角度は約-8°〜-10°。中の文字とアイコンは傾けない）。
  - 主役の「学習サイクル(MAIN QUEST)」を**最も大きい注目タイル**にし、金〜琥珀の縁取り＋内側に薄い光、
    背景はルーンの紋様や魔法陣が透けるダークレッド/深い藍の質感。選択状態のような強い縁取り。
  - 他のメニュー（スキル/アイテム/必殺技/ステータス/学習記録/バトル/弱点克服/ご意見箱 等）は、
    黒〜ダークネイビーの石板/黒曜石のような質感の斜めタイルに、**金または単色のアイコン**（絵文字は避けSVGか装飾された記号）。
    タイルごとにアクセント色を変えてよい（金・琥珀・青緑・紫・ローズ）。
  - 下段に、六角形/切り欠きの小さなボタン（ご意見箱・おしらせなどの補助）。
  - 学年切替(中1/中2/中3)は斜めタブ。通貨・レベルは金属プレート風。
  - 背景は空中学園の画像＋暗い半透明の帯で読みやすく、遠くに魔法陣とルーン文字がゆっくり回る（控えめ）。
- ファンタジー要素: 金の唐草/フィリグリーの角飾り、ルーン紋様、羊皮紙・黒曜石・星図の質感、
  タイルを選ぶと光の粒が舞う、押すと紋章が光る。
- 文字: 見出しはセリフ体(Cinzel / Shippori Mincho)、本文は落ち着いたゴシック(Noto Sans JP/Zen Kaku Gothic New)。
  丸ゴシックや太いポップ体は使わない。字間広め。色は象牙・淡金・淡シアン。
- 全ボタン・全機能は維持（消さない・順序の意味を変えない）。

## 守ること
- 編集は数学ラボ3フォルダ内のみ。他は読むだけ。ブランチ design-v2 上、コミット不要。
- **Home.jsx は別作業が並行して編集中**。現在の作業ツリーに入っている `import MedalCase from "../third/MedalCase.jsx"` と
  `<MedalCase .../>` の行は**そのまま残す**（削除・移動しない。見た目のラップは可）。
  触らないファイル: src/third/ 配下、scripts/sim-gauge-battle.mjs、src/data/toketa/、docs/supabase_third_setup.sql。
- ロジック・データ・保存キー・認証は変えない。iPhone横(844x390)/iPad/PCで崩れない。prefers-reduced-motion対応。
- 最後に npm run build を通し、docs/DESIGN_CHANGELOG_TITLE_MENU.md に変更点を日本語で記載。
