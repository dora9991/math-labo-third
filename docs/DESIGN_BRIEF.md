# 数学ラボ3 デザイン刷新ブリーフ

## 前提
- このフォルダ（数学ラボ3）だけを編集する。他のフォルダ・リポジトリは絶対に触らない
  （特に ../数学ラボ2 ../math-dialogue ../math-labo2 は編集禁止）。
- 数学ラボ2の機能・ロジック・データ・採点・保存キーは変更しない。変えるのは見た目のみ
  （CSS、色、フォント、背景、ボタン、文字、アイコン、演出、画像素材、className/インラインstyleの見た目部分）。
- 参考サンプル: docs/reference-astra/（前回Codexが作った「Astra Academy」= 星空・天空の学園の世界観。
  astra.css と astral/ 画像3枚）。このクオリティと統一感を目標にする。

## 目指す世界観
- 数学ラボ2の「数式・機械的」な雰囲気（数式、グリッド、回路/計器、HUD、ホログラム）を残しつつ、
  Astraサンプルのような美しい背景・ガラス質パネル・光るボタン・上品な文字組みで全面刷新。
- 背景、ボタン、文字（フォント・サイズ・色）、カード、ヘッダー、バトル画面、ホーム、単元選択、
  結果画面、教師モードまで、全画面で統一感を持たせる。
- 小中学生が使う。読みやすさ（コントラスト・文字サイズ・タップ領域44px以上）を最優先。
- iPhone横画面・iPad・PCで崩れないこと。

## 進め方
1. src/ の画面構成とスタイルの当たり方を把握（screens/ components/ styles）。
2. デザイントークン（色・影・角丸・フォント）を先に定義し、全体へ適用。
3. 背景画像などの素材は public/ 配下に置く（画像生成ができなければCSSグラデーション/SVGで代用）。
4. `npm run build` が通ることを必ず確認。
5. 変更内容を docs/DESIGN_CHANGELOG.md に日本語で要約。
