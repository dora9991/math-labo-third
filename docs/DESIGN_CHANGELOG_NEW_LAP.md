# 「もう一周」（2周目）（2026-10-20）

生徒の要望：「学年を全部終えたら、持っているキャラはそのままで、もう一周できるようにしてほしい」。

## 遊び方
- **中1・中2・中3をぜんぶクリア**すると、メニュー（冒険の書）に「🎉 全学年クリア！ もう一周できるよ」と「🔁 もう一周する（2周目）」が出る。
- 押すと確認が出る（残るもの／戻るもの／2周目のきまり）。「もう一周する！」で2周目スタート。メニューに「🔁 2周目　敵が少し強い（×1.25）」の印が出る。
- 2周目をぜんぶクリアすると、また「もう一周する（3周目）」が出る（何周でも）。

## 何が残って、何が戻るか（kazu の選択：「物語の進みだけ戻す」）
| そのまま残る | はじめに戻る |
|---|---|
| 仲間・レベル（経験値）・限界突破・予備・パーティ・ニックネーム／クリスタル／図鑑／**メダル**（はいち・れんしゅう・バトル）／ガチャの天井／裏ボスと協力プレイの記録・メダル／学習の記録（解答の履歴） | **バトルの順番**（また 1章の1つ目から）／「はじめてクリア」の記録（経験値・クリスタルがまた入る）／章クリア・章ボス・学年クリア |

- 裏ボスは、2周目以降もずっと開いたまま（2周目に入れたのは全学年クリア後だから）。「ものがたり」の見返しも、周が変わっても全部見られる。
- メダルは「集めたもの」なので消さない。バトルの順番・章ボスの開放だけを、この周のクリア（`state.lapBattle`）で決める（1周目は従来どおり `medals.battle`）。

## 2周目以降のごほうび（kazu の選択：「経験値は同じ・クリスタルは半分」）
- 「はじめてクリア」の**経験値は1周目と同じ**。**クリスタルは半分**（切り上げ・最低1）：小単元 2→1、章クリア 5→3、章ボス 5→3、学年クリア 30→15。
- 1周で入るクリスタルは約470個（ガチャ約95回）→ 2周目は約半分。周回のクリア（2回目以降）の 💎1・1日10回までは、これまでどおり。
- 裏ボス・協力プレイの記録は周回で戻さないので、そちらの「はじめて」のごほうびは増えない。

## 敵の強さ（kazu の選択：「1周ごとに少し強く」）
- 敵（雑魚・ボス・章ボス）の**HPと攻撃が、1周ごとに +25%**（2周目 ×1.25／3周目 ×1.5）。裏ボスは変えない（もともと推奨レベルで決まっているため）。
- 調整は `src/third/lap.js` の `LAP.enemyStep`（0.25）・`LAP.crystalMul`（0.5）だけ。

## しくみ
- 保存：`state.lap = { n, startedAt, history:[{n,endedAt}] }`、`state.lapBattle`（2周目以降のこの周のバトルクリア）。**SQL変更なし**。古いデータは1周目として読む。
- 新しいサーバー操作 `new_lap`（`core.js` の `startNextLap`）。**全学年の `gradeDone` がそろっていないと拒否**（`not-finished`）。仲間・メダル等には触らない。
- 画面：`ThirdMenu.jsx` のカードと確認（`body` に直接出す。入れ物の変形で画面いっぱいにならないため）、`App.jsx` の `doNewLap`、`ThirdBattle.jsx`（敵の強さ）、`SecretBossList.jsx`・`storyRun.js`（周が変わっても開いたまま）。
- 管理者のクリア操作（`adminOps.js`）は、2周目以降も「この周のクリア」に反映する。

## 公開するときの順番
新しいサーバー操作 `new_lap` があるので、**先に関数を再登録 → あとでサイト公開**。古い関数のままだと、ボタンを押しても「うまくいかなかったよ」になる（それ以外は動く）。
