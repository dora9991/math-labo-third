# 協力バトルでスキルを使えるようにする（2026-10-14）

「マルチプレイでスキルが使えない」への対応。仲間（SPECIALIST_ROSTER 140体）のスキルは実際には4種類だけ：**全体攻撃・単体攻撃・回復・状態異常回復**。これを協力バトル（`raidBattle.js`）で使えるようにした。

## 遊び方
- 自分の仲間の下に**スキルゲージ**が出る。**その子の持ち主が正解するたびに +1**（不正解・答えなかった人のキャラは貯まらない）。
- 満タンになると、その子の枠が光る。**タップ → 確認 → 「使う」**。ゲージはすぐ0に戻り、「⚡よやく」が付く。
- 効果は**そのラウンドの結果が出るときに**出る（みんなが答え終わる／時間が切れたとき）。答えが合っていなくても効く（一人用と同じ「ボーナス行動」）。ただしゲージは自分が正解しないと貯まらない。
- 結果の欄に「🌪️ アリス の「計算の全体波動・小」！ 敵に 166 ダメージ」のように、誰のスキルかが全員に出る。技名の演出も出る（HypeFx）。

## スキルごとの効き方
| 種類 | 協力バトルでの効果 |
|---|---|
| 全体攻撃・単体攻撃 | 敵（協力バトルは1体ずつなので、全体も単体も同じ）に、その子の通常攻撃の ×倍率。**1回で削れる量は敵の最大HPの12%まで**（`RB.skillCapFrac`）。 |
| 回復 | みんなのHPを最大の○%回復（一人用と同じ数値：5〜20%）。 |
| 状態異常回復 | 協力バトルでは状態異常が出ないので、**みんなのHPを最大の12%回復**に置きかえ（`RB.cureHeal`）。画面の説明にもそう出る。 |
| それ以外（バフ・妨害など） | いまの仲間は持っていないので未対応（`coopSkillOf` が null＝ゲージも出ない）。持たせるときは `coopSkillOf` に足す。 |

## ゲージの貯まり方
- 満タンに必要な正解数 ＝ 一人用の値（N=6・R=9・SR=12・UR=15／回復6〜12／状態異常回復12）× **0.75**（切り上げ・最低2）＝ N=5・R=7・SR=9・UR=12。1ステージが一人用より短いため（`RB.skillGaugeMul`）。
- 一人用と同じ関数 `skillGaugeMaxFor`（`skillDefs.js` に移した）を使う。

## しくみ（サーバー）
- `room.battle` に `gauge: { "持ち主:キャラID": 正解数 }` と `queue: [{key,uid,id,at}]`。**SQL変更なし**。同じ子を2人が持っていても区別する（キーに持ち主を入れる）。
- 新しい操作 `room_battle_skill { code, charId }`（`raidBattle.js` の `queueSkill`）。ゲージが満タンの**自分の**キャラだけ。足りない・もう予約した・戦闘が終わった等は「害のない無視」（画面が追いつくだけ）。パーティにいない子・スキルが無い子は400。
- `resolveRound` が、予約を**先に**効かせる（ダメージは みんなの攻撃と合わせて敵のHPから引く／回復は敵の反撃の前）。そのあと正解した人のキャラのゲージ+1。部屋を出た人の予約は出ない。
- 古い戦闘（`gauge`・`queue` が無い）でも壊れない。

## バランスの調整（重要）
スキルを入れると、同じ敵の強さのままでは勝ちやすくなりすぎる（普通の子だけのチームが 3〜62% → 85〜100%）。そこで、スキルが無かったときの勝率にそろうよう、敵を少し強くした（`scripts/sim-raid-battle.mjs`・3人・各80回。生徒は満タンになったらすぐ使う／回復はHP75%未満のときだけ）。

| 変えた値 | 前 → 後 |
|---|---|
| `RB.bossHp` | 0.41 → 0.52 |
| `RB.hpGrowth` | 1.2 → 1.5 |
| `RB.bossDmgFrac` | 0.085 → 0.10 |
| `RB.mobDmgFrac` | [0.03, 0.045] → [0.034, 0.05] |

勝率（ステージ1／6／11／16／21）：
- スキル無し（前の設定）：普通 62／3／30／78／62・混合 95／48／82／100／87・得意 100／92／97／100／100
- スキル有り（今の設定）：普通 50／23／40／81／93・混合 93／60／75／100／100・得意 96／89／96／100／100
- 苦手な子ばかりのチームは、どちらも勝てない（0%）＝「教室に得意な子がいてほしい」という設計のまま。
- スキルは与ダメージの1〜2割（序盤のNの子は多め）。1ステージ 約6〜8分のまま。

## 変更したファイル
- 変更：`raidBattle.js`（`RB`・`coopSkillOf`・`coopGaugeMax`・`coopSkillText`・`slotKey`・`queueSkill`・`resolveRound`）、`skillDefs.js`（`skillGaugeMaxFor` を移動）、`ThirdBattle.jsx`（その関数を取り込む＝動きは同じ）、`handler.js`（`room_battle_skill`）、`thirdApi.js`、`CoopBattle.jsx`・`coop.css`（ゲージ・光・確認・よやく・結果の行）、`scripts/test-third-raid.mjs`・`scripts/sim-raid-battle.mjs`、`bundle/index.ts`（再生成）
- 協力バトルで、自分の仲間の下に出る名前は、ニックネームをつけた子ならそのニックネーム（他の人には持ち主の名前のまま）。

## 公開するときの順番（これまでと同じ）
新しい操作が増えるので、**先に関数を再登録 → あとでサイト公開**。古い関数のままだと、スキルをタップしても「スキルを使えなかったよ」になる（それ以外は動く）。

## まだ入っていないこと
- バフ・妨害系のスキル（いまの仲間は持っていない）。
- 協力バトルでのスキル使用は、学習ログ・毎日の目標には入らない（答えの記録だけが対象のまま）。
