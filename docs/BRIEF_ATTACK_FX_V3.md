# 数学ラボ3 攻撃演出をもっと派手に（V3）

## 依頼（kazu 2026-09-25）
数学ラボ3のバトルで、**味方の攻撃（正解した瞬間に仲間全員が攻撃する演出）と、敵を倒した瞬間**を、いまよりずっと派手で気持ちいい演出にしてほしい。
「強い攻撃を当てた！」という手応えと爽快感、テンションの上がる見た目・音にする。世界観は Astra（深い藍・淡いシアン・古金・すみれ色、光る魔法）。

## 現状（読んで把握すること）
- 演出は PixiJS：`src/third/fx/BattleFX.jsx`（`playHit`＝球が飛んで着弾・爆発・ダメージ数字、`spawnAttackKind`＝通常攻撃5種、`spawnUltimate`＝必殺技、`flashScreen`、`spawnBurst` など）。呼び出しは `src/third/screens/ThirdBattle.jsx`。
- 効果音は `src/third/fx/sound.js`（合成音＋一部実音源。攻撃開始音は12%に絞ってある＝重なって耳が痛くならないため。この音量バランスは大きく変えない）。
- 演出の速さ設定 `speed`（ふつう／はやい／オフ）と `prefers-reduced-motion` に従う（`src/engine/fxSpeed.js`）。
- 過去の指示書：`docs/BRIEF_ATTACK_ORB.md`、`docs/battle-fx-work/`、`docs/DESIGN_CHANGELOG_*.md`（変更記録の書き方の参考）。

## やりたいこと（優先順）
1. **着弾を派手に**：着弾の瞬間の「ヒットストップ（ごく短い間）」「画面の白フラッシュ＋色フラッシュ」「衝撃波リングの多重化」「放射状の光条」「破片・火花・光の粒（数を増やす）」「画面ズームのパルス（一瞬 1.03〜1.06倍）」「画面シェイク」。敵は白くフラッシュしてのけぞる（すでにある演出を強める）。
2. **ダメージ数字を大きく・ド派手に**：着弾の瞬間にドンと出て、跳ねて、金縁。ダメージの大きさで段階（小／中／大／特大）を分け、特大は「CRITICAL!」等のラベル・虹〜金のグラデ・大きな縁取り・拡大バウンス。数字は読みやすさを最優先（縁取り・影）。
3. **コンボ感**：連続正解（連続で正解し続けている間）で演出が段階的に豪華になる（3連続・5連続・10連続で球のサイズ・色・粒子・追加リングが増える）。連続数は画面の端に小さく「COMBO ×N」を出してよい。**連続数の管理は ThirdBattle 内の演出用の state/ref とし、ダメージ・HP・報酬などのロジックには絶対に影響させない。** 不正解で途切れる。
4. **撃破の瞬間**：敵のHPが0になった時に、大きな爆発（多重リング＋光柱＋破片が四散＋一瞬のスロー感・ズーム）を追加。ボスは特に大きく。
5. **球の飛翔**：球を大きく・多層グロー・尾（トレイル）を長く・火花を散らす。3〜5体の仲間の球が少しずつずれて飛び、最後に一点に集まるような「一斉攻撃」感。系統色（計算=青、方程式=紫、関数=緑、図形=橙、データ=ピンク）を生かす。
6. **効果音**：着弾の重い低音・きらめきを少し足す（合成音でよい）。ただし連続正解で音が濁らないよう、同時発音数を制限し、全体の音量は今より大きくしない（既存の limiter/バスを使う）。
7. 必殺技（スキル）の演出も、上と同じ方向で少し強める（カットイン後の発動は既存の仕組みを壊さない）。

## 守ること（重要）
- **ゲームロジックは一切変えない**：ダメージ計算・HP・ゲージ・出題・報酬・サーバー通信・状態遷移の順序と結果。見た目のタイミング（ダメージ数字やHPバー減少を着弾に合わせる程度）は可。
- **テンポを落とさない**：この画面は30秒ゲージのリアルタイム戦闘で、正解直後（約30ms後）に次の問題が出る。演出は**次の問題の操作をブロックしない**（非同期で並行再生）。ヒットストップは演出内の見た目だけ（入力・ゲージ・タイマーを止めない）。
- **軽量に**：iPad・スマホで滑らかに。1回の攻撃の粒子は合計 100個程度まで、連続正解でも粒子オブジェクトを使い回し／上限を設ける。長時間プレイでメモリ・GPU負荷が増えない（アンマウント時・演出終了時に必ず片付ける）。
- `speed` が「オフ」または reduced-motion のときは、球を飛ばさず、短いフラッシュとダメージ数字だけにする。「はやい」は全体を速く。
- 文字・数字は読める大きさとコントラスト。ダメージ数字は隠れない位置に。
- 画面のシェイク・フラッシュは強すぎて目に悪くならないように（点滅は1秒に3回を超えない目安、白フラッシュのピークは0.8まで）。
- 既存の敵攻撃演出（`spawnEnemyAttack`）は今回は触らない。
