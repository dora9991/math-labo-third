# nagi 表情差分

基準: `docs/story-art/base/nagi.png`

| ID | 狙い | 結果 |
| --- | --- | --- |
| `nagi_happy` | 心からの明るい、口を開いた笑顔 | 完了。口を開いた朗らかな笑顔。 |
| `nagi_sad` | 悲しみ・後悔・さびしさ | 完了。下がった眉、伏し目、抑えた口元で静かな悲しみを表現。 |
| `nagi_surprised` | 驚き | 完了。見開いた目と小さく開いた口。 |
| `nagi_angry` | 真剣・厳しい・決意 | 完了。眉を寄せ、まっすぐ見据える決意の表情。 |

初回確認で `sad` と `angry` の表情が弱かったため、それぞれ1回再生成して採用した。生成画像は顔の目・眉・口領域だけを基準画像へ合成し、衣装・髪型・体つき・ポーズ・カメラ・全身フレーミングを基準のまま固定した。各最終PNGに `process_expr.py` を実行済み。比較用コンタクトシートは `docs/story-art/sheets/expr_nagi.png`。
