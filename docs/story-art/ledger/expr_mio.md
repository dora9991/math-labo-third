# mio 表情差分

基準: `docs/story-art/base/mio.png`

| ID | 狙い | 結果 |
| --- | --- | --- |
| `mio_happy` | 心からの明るい、口を開いた笑顔 | 完了。目を閉じた朗らかな開口笑顔。 |
| `mio_sad` | 悲しみ・後悔・さびしさ | 完了。下がった眉と伏し目による、抑えた悲しみ。 |
| `mio_surprised` | 驚き | 完了。見開いた目と小さく開いた口。 |
| `mio_angry` | 真剣・厳しい・決意 | 完了。まっすぐ見据える、引き締めた表情。 |

生成画像は初回に全身倍率のずれがあったため採用せず、基準画像を土台に各生成結果の顔領域だけを合成して、衣装・髪型・体つき・ポーズ・カメラ・全身フレーミングを保持した。各PNGに `process_expr.py` を実行済み。比較用コンタクトシートは `docs/story-art/sheets/expr_mio.png`。
