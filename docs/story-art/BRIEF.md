# ストーリー用 立ち絵・背景の生成（共通ルール）

対象: 数学ラボ3のストーリー（三部作）。脚本は Obsidian の `脚本_数学ラボ3ストーリー_*.md`。舞台は空に浮かぶアストラ天文台と、雲の海の浮島。
一覧は `docs/story-art/manifest.json`（characters / backgrounds）。**渡されたIDだけ**を生成する。

## 絵柄（凍結）
- 世界観: 「数学の研究施設が浮かぶ星空（ASTRA ACADEMY）」。深い藍・淡いシアン・古金・バイオレットが基調。添付画像 `public/astral/menu-academy.png`（と title/battle）が背景の品質・色の基準。
- **画像内に文字・数字・数式・ロゴ・透かしは入れない**（看板・名札・本の背表紙も読めない模様にする）。
- 血・残酷表現は禁止。子ども（中学生）が見て安心できる、やさしく少し切ない雰囲気。既存のゲーム/アニメのキャラに似せない（オリジナル）。

## 立ち絵（characters）※2026-09-24 画風を改訂（v1の半写実はkazuに「リアルすぎる」と言われたため没・`realistic_v1/`に退避）
- **ゲームのキャラクターらしい、デフォルメ寄りのアニメ調イラスト**。添付の `docs/story-art/style/ally_*.png`（ゲーム内の仲間モンスター）の親しみやすさ・線の太さ・塗りの質感に寄せる。
  - 3〜4頭身のバランス（大きな頭・大きな目・短めの手足）。はっきりした輪郭線、なめらかなセル塗り＋控えめなグラデーション。顔の表情が一目で分かる。
  - リアルな肌・皮膚の質感、細かすぎる皺や布の描き込みは禁止。小さく表示しても読める、シンプルで強いシルエット。
  - ただし幼稚すぎない：世界観（深藍・古金・淡シアンの上品なファンタジー）は保ち、衣装の主色と小物（ゴーグル・片眼鏡・星の刺繍など）でキャラを立てる。
- **透明背景・全身（ミラ・ノクスも全身）・正面〜3/4・1体のみ・床影なし・余白約4%**。
- 7体は同じ画風・線の太さ・彩度で統一（1つのセッションで続けて描く）。

## 背景（backgrounds）
- **16:9の横長・人物は描かない**（立ち絵を重ねる前提）。画面下1/3は会話ウィンドウが乗るので、細かい物を置かず落ち着いた面にする。
- 中央〜上に主役のモチーフ。奥行きと空気感（霧・光）。章ごとのアクセント色を主役にする。

## 手順
1. 各IDについて、組み込みの画像生成機能で生成する。文字混入・不透明背景（立ち絵のみ）・崩れ・複数体は破棄して作り直す（最大2回）。
2. 生成PNGを処理する:
   - 立ち絵: `python3 docs/story-art/process_char.py <生成PNG> <ID>` → `src/third/assets/story/characters/<ID>.webp`
   - 背景: `python3 docs/story-art/process_bg.py <生成PNG> <ID>` → `src/third/assets/story/backgrounds/<ID>.webp`
3. 作ったものを1枚のコンタクトシート `docs/story-art/sheets/<バッチ名>.png` にまとめ、目視で見比べて、品質が低いものは作り直す。
4. `docs/story-art/ledger/<バッチ名>.md` に「ID／狙い／完了・未完（理由）」を書く。

## 守ること
- 編集・作成してよいのは `docs/story-art/ledger/`, `docs/story-art/sheets/`, `src/third/assets/story/` だけ。**ソースコード(.js/.jsx/.css)や他ファイルは編集禁止**。
- 生成は計画だけで終わらず、渡された全IDを完了させる。
