# デザイン変更履歴 V3

## 実施した変更

- ホームを単なるカード一覧から、空中学園を背にした「ミッション選択ハブ」へ再構成しました。ヒーロー見出し、学年ワールドの金属プレート、先生の吹き出し、メインクエストの金縁リボン、サブメニューのイラスト風タイルで構成しています。
- タイトルの開始操作を、金縁・下側の厚み・内側ハイライト・定期的な光沢帯を持つスタートボタンへ変更しました。
- `src/components/GameButton.jsx` を新設しました。金／青紫／緑／ピンク／危険色に対応し、ベベル、shine sweep、押下時の沈み込みと星粒を共通化しています。
- バトルの選択肢・スキル・アイテムを立体的なコマンドデッキに変更しました。必殺技が使える時には虹色の READY 表示と脈動を追加しています。
- バトルは既存の攻撃・被弾・敵の待機／撃破演出を活かしつつ、ダメージ数値の跳ね、ステージのエネルギーパルス、必殺技カットインの ULTIMATE 帯を強化しました。
- 勝利時は `VICTORY / MISSION CLEAR` の金バナー、放射光、紙吹雪、報酬へつながるリザルトボタンを追加しました。通常バトルと行動選択型バトルの双方に適用しています。
- `prefers-reduced-motion` 時は、新しい常時アニメーション（紙吹雪、脈動、回転光）を停止します。

## 追加素材

- 新規ビットマップ素材は追加していません。既存の `public/astral/menu-academy.png` と `public/astral/title-sky-kingdom.png`、`public/astral/battle-observatory.png` を背景として活かし、フレーム・宝石感・紙吹雪・光は軽量な CSS で描画しています。

## 変更していないもの

- 学習ロジック、問題データ、採点、保存キー、認証、Supabase連携、バトルのHP・SP・ダメージ・報酬などの数値ルールは変更していません。
- 既存画面の遷移先、クリックハンドラ、ホームの機能メニュー項目は維持しています。

## 要判断点

- 実機での最終色味は、対象iPadの明るさ・反射を含めて確認するとよいです。文字の可読性を優先して背景には暗いベールを残しています。
- 開発サーバーは実行環境のポート制限（`EPERM ::1:5187`）により起動確認できませんでした。本番ビルドは成功しています。
