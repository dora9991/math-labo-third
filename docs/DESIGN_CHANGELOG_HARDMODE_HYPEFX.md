## 何ができたか

### ハードモード（バトル前にON/OFF）
- バトル画面の舞台の左上に「🔥 ハードモード OFF／ON」ボタン。**最初の解答・スキル発動・敵の最初の行動のどれかが起きるまで**切り替えられる。そのあとは固定（ONなら🔥バッジだけ残る）。バトル中に「負けそうだからOFF」はできない。
- 選んだ状態は端末に保存（`localStorage` の `mathApp3_hardMode`）。次のバトルも同じ。
- **途中からハードモードにすることはできない。** 1戦まるごと同じモードで、途中の波から切り替わることはない（固定のあとはボタンが消える／押せないバッジになる）。「ハードクリア」のような記録・バッジはまだ無く、ごほうびもふつうと同じ（必要なら、メダルなどのサーバー側の変更を伴うので別の作業になる）。
- ONの間の変化（数値は `src/third/hardMode.js` の `HARD_MODE` だけ直せばよい）：
  - 自分のダメージ ×0.5（通常こうげき・スキル両方）
  - 1回の正解で1体から削れる上限も ×0.5 ＝ **必要な正解数がおよそ2倍**（学習量のフロアも2倍）
  - 敵のこうげきダメージ ×1.25（ボスの大技・雑魚の通常攻撃。毒などの継続ダメージは変えていない）
- **ごほうび（経験値・コイン・クリスタル・メダル）は変えていない。** 報酬はサーバーが解答記録(seed・答え・時間)から決めており、クライアントで増やせないため。ハードモードで増えた解答はサーバーの検証内に収まる（下記）。
- **使えない場面**：お試し戦（demo、ごほうび無し）と裏ボス（もともと推奨Lvで勝率約45%に調整済み。ハードモードだと推奨Lvでは勝てなくなる）。ボタン自体を出さない。

### 派手な演出（見た目だけ。ダメージ・HP・出題・報酬・敵の行動には一切さわらない）
- **技名**：正解のたびに、その問題の章の技名を舞台の下端にさっと表示（例：1章「プラスブレード」「マイナスクラッシュ」「ゼロスラッシュ」）。同じ技が続かない。全21章ぶんの技名を `src/third/fx/attackMoves.js` に用意。
- **奥義**：連続正解が5の倍数に届いたとき、または**とどめの一撃**のとき、「奥義」タグ付きで大きく表示（金色・斬撃線・フラッシュ・大きめのシェイク）。
- **撃破フィニッシュ**：敵を倒した着弾に合わせて「撃破！」。ボス波の最後は「BOSS 撃破！」＋金のフラッシュ＋大きなシェイク。スキルで倒したときも同じ。
- **ハードモード突入**：ONにした瞬間（または前回からONのままバトルを始めたとき）、暗赤の縁取り・フラッシュ・シェイクと「🔥 ハードモード突入！」バナー。ONの間は舞台の縁に熾火の光がうっすら脈打つ。
- 演出の速さ設定（ふつう／はやい／オフ）に従う：はやい＝半分の長さ、オフ（OSの「視差効果を減らす」も含む）＝何も出さない。
- 光りすぎないよう、フラッシュのピークは0.5〜0.7に抑え、会心では光らせない（既存の `CRITICAL!` と重ねない）。撃破の金の光は既存の `playDefeat`（BattleFX）にあるので重ねない（ボス波だけ追加）。

## 確認したこと
- `node scripts/verify-hard-mode.mjs`：93 passed / 0 failed。
  - ふつうは倍率1で従来と同じ値／ハードモードは 100→50・125、最低1、0は0のまま。
  - ハードモードの必要な正解数は約2倍（HP 500〜381306、全難度）。
  - 全小単元（雑魚3体×2波＋ボス）・章ボスで、ハードモードの最小正解数の最大は **76問**（3年 g3c8）。サーバーの解答数の上限 `VERIFY.maxAttempts = 300`（超えると申請そのものが失敗）の4分の1以下で、不正解を含めても余裕がある。
  - 全21章に技名がある／とどめと5の倍数で奥義／同じ技が続かない。
  - `ThirdBattle.jsx` の配線（`scaleTaken` 1か所、`scaleDealt`/`scaleCap` 3か所以上、`lockHardMode` 3か所以上）と、`finishBattle` にハードモードの値が入っていないこと。
- Chromium（スマホ縦 390×844）で実際のバトル（1章1小単元）を操作：
  - ボタンのON/OFF（保存・突入演出）、最初の解答で固定（ボタン→🔥バッジ）、OFFで固定されたときは何も出ない。
  - 最初の敵を倒すまでの正解数：ふつう6問 → ハードモード10〜12問（乱数で敵の数・HPが毎回違うので目安）。
  - 敵のこうげき（乱数を固定して1回分）：67 → 84（×1.25）。
  - 技名の表示、5連続の奥義、撃破表示、演出スピード「オフ」で何も出ない／「はやい」で短く出る。コンソールエラーなし。
  - ハードモードONのまま**1戦まるごと**（2波＋ボス、正解49問・約85秒）勝って、結果画面まで到達。「クリア！ 経験値+105／バトルメダル／💎+2／今日の目標 💎+1」が通常どおり出た（サーバーの申請が通り、ごほうびはハードモードでも変わらない）。
- `npm run build` 成功。

# 追記（2026-10-09）：ボス1体の戦いで「勝ったのに、ごほうびが無い」不具合の修正

配信前の最終確認で見つかった不具合（公開中の版にもある）。

- **症状**：強いパーティで章ボス・裏ボスを倒すと、「クリア！」のあとに「正解がたりなかったので、ごほうびはなかったよ」となり、
  ごほうびもクリアの記録も付かない。章ボスの記録（`bossDone`）が付かないと学年クリア（`gradeDone`）にならず、裏ボスも開かない。
  裏ボスは次の裏ボスが開かない。
- **原因**：サーバーが「倒した」と認める最低の正解数は、章ボス 6（`VERIFY.minCorrect`）・裏ボス 15（`SECRET.minCorrect`）。
  一方、画面のバトルでは1回の正解で敵の最大HPの20〜50%（`capFrac`）、スキルで35%まで削れるので、ボス1体だけの戦いは
  2〜5問の正解で倒せてしまう（小単元は3戦あるので6問に必ず届き、問題なし）。
- **確認**：UR Lv40 で1章の章ボスを4問で撃破 → ごほうび無し・`bossDone` 空。UR Lv70 で裏ボス1を7問で撃破 → ごほうび無し。
  学年を通したシミュレーションでは、得意な生徒の章ボス初勝利の7〜8%がこれに当たっていた。
- **修正**（`src/third/screens/ThirdBattle.jsx` のみ。サーバーは変えていない）：
  - `needCorrect`（ごほうびを申請する戦いだけ：章ボス6・裏ボス15・小単元6）と、記録した正解の数 `correctCountRef` を持つ
    （速すぎる解答・10分を超えた解答はサーバーと同じく数えない）。
  - 章ボス・裏ボスは、1回の正解・スキルで1体から削れる量を「最大HP ÷ 必要な正解数」までにする（`bossHitCap`）。
    弱い〜ふつうのパーティは、もともとこの上限より小さいダメージなので変化なし。強いパーティは最低6問（裏ボス15問）かかる。
  - それでもスキル等で先に削り切りそうなときは、必要な正解数がそろうまで最後の敵がHP1で踏みとどまり、
    「まだ倒れない！ あと○問 正解で とどめ！」と表示（`applyDamageToEnemies`）。
- **修正後の確認（Chromium）**：章ボス UR Lv40 普通 → 7問・UR Lv40 鬼 → 6問・UR Lv70 鬼 → 6問で、いずれも
  「章ボスを はじめて たおした！ 💎+5」と `bossDone` の記録あり。裏ボス1：SR Lv30 → 17問・SR Lv40 → 17問・UR Lv70凸3 → 17問で、
  いずれも「裏ボスを はじめて たおした！ 💎+3・経験値+1900」と記録あり。スキルを連発した場合は HP1 で踏みとどまり、
  15問目の正解でとどめ→ごほうびあり。小単元の通常バトル（ふつう・ハード）は従来どおり。
