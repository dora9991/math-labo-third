# 敵モンスター全面刷新 — 章ごとの生成（共通ルール）

## 目的
数学ラボ3（空中学園 ASTRA ACADEMY）の敵を、**世界観に合う、やや写実的で重厚なダークファンタジーのキャラクターデザイン**に一新する。
**ボスは全員違うデザイン**（この章の中はもちろん、全章・全体でシルエットが被らない）。雑魚も1体ずつ別デザインにする（色違い禁止）。

## 絵柄（凍結。必ず守る）
- 添付の `docs/enemy-work/pilot-sheet.png` と `docs/enemy-pilot/README.md`（絵柄ガイド）が基準。パイロット10体と同じ品質・質感・世界観で描く。
- 質感: 黒曜石、深藍の装甲、古びた金、発光する結晶。光: 下方から淡いシアンのリム光、背後に小さな魔法陣/後光。
- 数学モチーフ（数・図形・グラフ・天秤・サイコロ・天文器具など）は「構造や意匠」として組み込む。**画像内に文字・数字・数式・ロゴ・透かしは入れない**。
- 血、グロテスクな損傷、残酷な武器表現は禁止。威厳と不穏さは光・材質・姿勢で出す。既存ゲーム/アニメのキャラに似せない（オリジナル）。
- 小さく(96px)表示しても種類が分かる**輪郭(シルエット)の違い**と、目の発光、主モチーフを優先。細い装飾は増やしすぎない。
- 章ごとのアクセント色を主役にする（黒曜石・深藍・古金・淡シアンのベースは共通）。章のアクセントは下記の指定に従う。

## 役割ごとの大きさ・威厳
- unit（雑魚）: 小〜中型でコンパクト。1体ずつ別の生き物/構造物。名前（例: スウチビット）とテーマ(単元)に合う造形にする。
- unitSmallBoss（小単元ボス）: 雑魚より一回り大きく威厳。同じ小単元の雑魚とは全く別のシルエット。
- unitBoss（試練・最終段）: さらに重厚。章ボスの一つ手前の関門。
- chapterBoss（章の主）: この章で最大級の威厳。章全体のテーマを背負う。

## 手順
1. `docs/enemy-work/manifest.json` の該当章の敵（下記リスト）について、まず**コンセプト台帳** `docs/enemy-work/ledger/<章ID>.md` を書く
   （ID／名前／役割／コンセプト一文／シルエット系統／主モチーフ／アクセント色）。**既に存在する他章の台帳を全部読み、シルエット系統とモチーフの重複を避ける**。
   章内でも同じ系統(例:「鳥」「亀」「人型」「獣」「浮遊体」「多脚」「蛇・竜」「植物」「機械」「結晶柱」「魚/水棲」「甲殻」…)が続かないようバラけさせる。
2. 各IDについて、組み込みの画像生成機能で **透明背景・全身・正面〜3/4ビュー・床影なし・余白約6%・1体のみ** の画像を生成する。
   生成物が不透明背景/文字混入/切れ/2体以上/シルエットが他と被る場合は破棄して作り直す（最大2回。それでも駄目なら台帳に理由を書いて次へ）。
3. 生成したPNGを `python3 docs/enemy-work/process_png.py <生成PNGのパス> <ID>` で処理する
   （→ `src/third/assets/monsters/by-id/full/<ID>.webp` 512px と `small/<ID>.webp` 96px が出力される）。
4. この章の全画像を1枚のコンタクトシート `docs/enemy-work/sheets/<章ID>.png`（暗い背景に並べる）にして自分で見比べ、
   似たシルエット・品質が低いもの（崩れ、余計な文字、目が無い等）があれば作り直す。
5. 章の末尾に台帳へ「完了/未完(理由)」を書く。

## 守ること
- 編集/作成してよいのは次だけ: `docs/enemy-work/ledger/`, `docs/enemy-work/sheets/`, `src/third/assets/monsters/by-id/`。
  **ソースコード(src/の.js/.jsx/.css)や他ファイルは編集禁止**。他フォルダも禁止。
- 既に `by-id/full/<ID>.webp` がある敵はスキップ（パイロットで完成済み）。
- 他の作業（別の章のCodex）が並行して同じフォルダに書き込む。**自分の章のIDのファイルだけ**を作る/消す。他章のファイルは触らない。
- 生成に時間がかかる場合も、この章の全IDを完了させること（計画だけで終わらない）。
