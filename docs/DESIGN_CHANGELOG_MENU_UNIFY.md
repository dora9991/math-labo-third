# メニュー画面デザイン統一 — 変更記録

実施日: 2026-09-21

## 変更した画面・共通部品

- `src/third/menu/ThirdMenu.jsx`
  - メインを「学習を始める」主役タイルと、学習記録／パーティ編成／設定の補助タイルに再構成した。
  - 見出しタブを `ASTRA ACADEMY ── 冒険の書` とし、斜めに切ったタイルの中では文字を水平に保った。
  - 単元、小単元、アクション選択は共通の見出しと `GameButton` の外観を使用するようにした。
- `RecordScreen.jsx`、`SettingsScreen.jsx`、`AlarmOverlay.jsx`
  - 黒曜石パネル、金の細線、明朝系見出し、切り欠きボタンへ統一した。
  - 記録カードの区分はローマ数字に置き換え、装飾的な絵文字への依存を減らした。
- `MedalCase.jsx`
  - 判定・データ・操作ロジックを変更せず、CSSフックを追加してメニューの金縁パネルに統一した。
- `GameButton.jsx`、`Header.jsx`、`UnitCycle.jsx`
  - ボタンの既存 API を維持したまま、主なメニューアイコンをオリジナルの線画 SVG に置換した。
  - ヘッダーのロゴ、通貨・レベル表示、戻る操作を金属プレート／切り欠き形に統一した。
  - UnitCycle に表示用クラスだけを追加し、既存ハンドラ・進捗判定は変更していない。
- `src/styles/theme.css`
  - 共通トークン（黒曜石、深藍、象牙、淡金、淡シアンとアクセント色）、背景画像の単枚 `cover/no-repeat/center` 指定、魔法陣の控えめな回転、主役タイル、レスポンシブ／reduced-motion 対応を追加した。
- `src/third/third.css`
  - メニューから遷移するパーティ編成・ガチャ・報酬の既存 DOM を、同じ空中学園背景、黒曜石パネル、金縁、明朝系の見出しへ統一した。

## 触らなかったもの

- メダルのサーバー化に関係する指定禁止ファイル（`medals.js`、`thirdApi.js`、`link.js`、`ThirdContext.jsx`、`App.jsx`、`supabase/`、`scripts/` など）は編集していない。
- Pixi/戦闘ロジック、バトルエンジン、保存キー、API呼び出し、データ・条件分岐は変更していない。
- `src/screens/Home.jsx` は未使用との指定に従い編集していない。

## 判断が必要な点

- バトル本体は指定により描画・演出を変更していない。パーティ編成、ガチャ、報酬などメニュー起点で DOM/CSS を持つ画面のみ統一している。
- 既存データ内の単元絵文字・メダル状態アイコンは情報識別のため残るが、メインナビゲーションのアイコンは線画 SVG に変更した。
