# 脚本_数学ラボ3ストーリー_中3編_館長とナギ_2026-09-24

中1・中2編の続き＝**最終編**。方針は同じ：**物語に数学の知識は入れない**。敵の総称は**カゲ**。
章は中3の8単元（式の展開と因数分解／平方根／2次方程式／y=ax²／相似／円／三平方の定理／標本調査）＝**ナギの塔の8つの階**。小単元（全35）は見出しの括弧に残した。

## 中1・中2編からの引き継ぎ（回収するタネ）
- 天文台の地下の**鍵のかかった扉**と、そこに刻まれた名前**「ナギ」**（中2最終章）。
- フクロウの「約束」と、「ナギ……ずっと、ずっと前の名前だ」（中2）。
- **きみが、あの夜に選ばれた理由**（中1プロローグ。フクロウは「やっと、見つけた」と言った）。
- 館長が「わたしには、閉じこめることしかできなかった」と言ったこと（中1最終章）。
- ジンの「館長に答えてもらえなかった」（中2）。

## 今回の新キャラ
- **ナギ**：館長の娘。生きものの「もういいや」が、聞こえてしまう子だった。10年前から、鍵の扉の向こうで眠っている（時間が止まっていて、14歳のまま）。
- **館長**：今回から同行し、自分の過去と向き合う。

## この編の芯
- **カゲの正体＝「聞いてもらえなかった気持ち」**。ナギは、みんなの「もういいや」を聞いてあげる子だった。聞いてもらえれば、それはカゲにならない。
- **館長のあやまち**：ナギが一度たおれた夜、それだけを見て「この子は、この世界に耐えられない」と決めた。ほんとうは、ナギは**聞きつづけたかった**。（＝一部を見て、全体を決めつけた）
- **きみが選ばれた理由**：ナギがフクロウに頼んだ。「『わからない』って言える子を、さがして」。
- 結論：**「わからない」「もういいや」を、言える場所と、聞いてくれる人がいれば、カゲは生まれない。**

## 批評（役割3名）

- **①中3の子ども**：受験前の子には「わからないって言っていい」が、いちばん効く。ナギの結論（言える場所と聞いてくれる人）は、そのまま学習アプリの約束になる。ただし館長の後悔の場面は、大人向けに重い。子どもには**ナギが起きたあとの明るい場面**を、しっかり長めに。
- **②「ゲームに飲まれる番人」（6/22の自分）**：中3は35小単元。各場面を1つ6〜8行に抑えた。それでも会話画面はスキップ可能に。数学は物語にゼロ。
