# 攻撃演出 V3 変更記録

## 変更内容

- `BattleFX.jsx` の着弾を、白（最大 0.78）→系統色の短い二段フラッシュ、多重衝撃波リング、放射光条、火花・光粒へ強化した。既存のPixi tickerで寿命終了時に各オブジェクトを破棄する。CSS側では18%のごく短い静止を含むズームパルスを重ね、入力・ゲージ・タイマーを止めない視覚上だけのヒットストップにした。
- 飛翔オーブは既存の多層グロー／長いトレイルを維持し、連続正解の段階に応じて大きくした。パーティ全員の弾は既存の30msずつのずらしをそのまま使う。
- ダメージ数値は `damageTier` で小（<35）／中（35〜89）／大（90〜179）／特大（180以上またはクリティカル）に分けた。特大は虹〜金のグラデーション、太い縁取り、影、バウンス、`CRITICAL!` または `POWER HIT!` を表示する。
- 正解連続数は `ThirdBattle.jsx` の `comboRef` / `combo` のみで管理し、不正解で0へ戻す。3・5・10連続で着弾のリング／光条とオーブの大きさを上げ、端に `COMBO ×N` を表示する。この値はダメージ・HP・報酬・出題・通信処理へ渡さない。
- 敵撃破は多重爆発、追加バースト、光柱、金色フラッシュにした。最終波（ボス）はさらに大きい段階で再生する。
- 着弾には低い衝撃音と短いきらめきを追加した。既存の攻撃専用リミッターバスに接続しており、既存素材の音量（開始・着弾ともに12%）は変更していない。
- 必殺技も既存の技別シルエットを残したまま、発動地点にV3の着弾を一段追加した。
- `speed=off` / reduced motion の既存分岐は維持し、飛翔を省略して短い着弾と数字のみを表示する。既存の敵攻撃演出は未変更。

## 調整箇所

- 着弾量・連続段階: `src/third/fx/BattleFX.jsx` の `spawnV3Impact`。`combo >= 3/5/10`、`rings`、`rayCount` を調整する。
- ダメージ文字の境界・大きさ: 同ファイルの `damageTier` と `spawnDamageText` の `fontSize`。
- オーブの連続時のサイズ: `playHit` の `size` 式。
- 一斉攻撃の時間差: `src/third/screens/ThirdBattle.jsx` の `STAGGER_MS` と `STAGGER_JITTER_MS`。
- ズームパルス: `src/third/third.css` の `mwImpactPulse`（最大 `scale(1.035)`）。
- 補助音の強さ: `src/third/fx/sound.js` の `playImpactAccent`。攻撃専用リミッターを経由する。
