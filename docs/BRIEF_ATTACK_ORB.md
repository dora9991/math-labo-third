# 攻撃エフェクト作り直し「強そうな球が飛んで、当たってバン！と爆発」

## 依頼
プレイヤーの攻撃を、次の演出にする:
1. **チャージ**: 主人公の手元/前に光の球が生まれ、エネルギーが集まる（0.25秒程度、光の粒が吸い込まれる）。
2. **発射**: 強そうな球（芯は白、外側はシアン→バイオレット→金の多層グロー、回転する光の輪、周囲に数式記号π∑√などが少し舞う）が
   主人公から敵へ、少し弧を描いて高速で飛ぶ。後ろに尾（トレイル）と火花が残る。拡大しながら加速する。
3. **着弾**: 敵に当たった瞬間に「バン！」と爆発:
   画面全体の一瞬の白フラッシュ、中心から広がる衝撃波リング(2重)、放射状の光条、飛び散る火花/破片、
   煙のような余韻、画面シェイク、敵の白フラッシュ＋のけぞり。ダメージ数字は着弾の瞬間にドンと出る（金縁で大きく跳ねる）。
4. **バリエーション**: 通常攻撃＝中サイズの青〜紫の球。ためた一撃/ファイアバースト等の強攻撃＝大きな球で色も炎系(赤〜金)、爆発も大きめ。
   クリティカル/大ダメージなら爆発をさらに大きく。
5. 実装は SVG / CSSアニメ / canvas のいずれか。再利用できる部品にする（例: src/components/AttackOrbFx.jsx ＋ CSS）。
   球の飛行の始点は主人公の位置、終点は敵の位置を実際のDOM位置から計算して、どの画面サイズでも当たるようにする。
6. TurnBattle.jsx（ターン制）と Battle.jsx（従来）の両方の攻撃に適用する。敵の攻撃側は今回は触らない。

## 守ること
- 編集は数学ラボ3フォルダ内のみ。他のフォルダは読むだけ。ブランチ design-v2 上で作業、コミット不要。
- ダメージ計算・HP・ターン進行・スキル効果などのロジックは変えない。演出の再生時間ぶん、見た目の表示タイミングを
  ずらす（ダメージ数字/HPバー減少を着弾に合わせる）のは可。ただし状態遷移の順序や結果は変えないこと。
- 連打や画面遷移で演出が残り続けない（アンマウント時に必ず片付ける）。
- prefers-reduced-motion では球を飛ばさず、短いフラッシュだけにする。
- 軽量に（iPadで滑らかに。パーティクルは合計50個程度まで）。
- 最後に npm run build を通し、docs/DESIGN_CHANGELOG_ATTACK_ORB.md に変更点・部品の使い方を日本語で記載。
