# 攻撃オーブ演出 変更記録

## 実装内容

- `src/components/AttackOrbFx.jsx` を追加した。主人公と敵の実DOM座標を取得し、画面サイズに依存せず主人公側から敵へオーブを飛ばす再利用部品である。
- 通常攻撃は白い芯、シアン・バイオレット・金の多層グロー、回転リング、数式記号、尾と火花を伴う中サイズの球として再生する。
- 必殺技・会心・コンボ・ダブルアップ等の強い攻撃は赤〜金の大きな球と大きめの爆発になる。
- 着弾時に白フラッシュ、画面シェイク、二重の衝撃波、放射光、煙状の余韻、最大18個の火花を表示し、その瞬間に敵のダメージ数字・HP減少・のけぞりを発生させる。既存のダメージ計算と勝敗・ターン順序は変更していない。
- `TurnBattle.jsx` と `Battle.jsx` のプレイヤー通常攻撃およびダメージを与える必殺技に適用した。敵側の攻撃には適用していない。
- アンマウント時には部品内タイマーをすべて解除する。`prefers-reduced-motion` では飛翔を省略し、短いフラッシュのみを出して着弾処理を行う。

## 使い方

`AttackOrbFx` に、始点となる主人公要素の `sourceRef`、終点となる敵要素の `targetRef`、連番の `attack={{ id, strong }}` を渡す。`id` が変わると演出を開始し、着弾時に `onImpact(id)` が一度呼ばれる。HP更新やダメージ表示はこのコールバック内に置く。

## 検証

- `npm run build`（Vite production build）成功。
