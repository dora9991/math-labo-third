# 敵モンスターのデザイン一新 — パイロット（絵柄の方向性を決める見本づくり）

## 依頼者の要望
「敵モンスターのデザインを一新したい。もっとこの世界観にあった、ちょっとリアリティのあるキャラクターデザインにして。
ボスのデザインは、できれば全員違うデザインがいい。」

## 現状（調査済みの事実）
- src/data/monsters.js の MONSTERS は240体: 雑魚(unit)87、小単元ボス(unitSmallBoss)32、ボスの梯子の最終段(unitBoss)42、
  章ボス(chapterBoss)21、裏ボス(secretBoss)54、最終ボス(finalBoss=学年の魔王)3、sample1。
- 画像は src/assets/monsters/{full,small}/*.webp の13アート型のみ（calc, prime, balance, fraction, geo, wave, angle, speed, volume, dice, ...）。
  **ボス152体は全員 art=boss の同じ1枚を色違い(imgHue)にしているだけ**。雑魚87体も13種を色違いで使い回し。
- 画像の解決: src/third/data/monsterImages.js（MON_IMG_FULL / small、アート型ごとに1枚＋hue-rotate）。
- 世界観: 空中学園「ASTRA ACADEMY」。星空、浮遊する天空都市、金と淡シアンと藍、数式・魔法陣・天文台。
  味方(パーティ)は可愛いデフォルメ系（docs/reference-astra/monster-sheet-*.png 参照）。敵はそれに対して
  **ダークファンタジー寄りの、やや写実的で重厚なコンセプトアート調**にする（子どもが怖がりすぎない範囲。血・グロ・武器の残酷表現は禁止）。

## 今回やること（コードは編集しない。画像と資料だけ）
1. 絵柄ガイドを決める: 描画の質感、ライティング(下から淡いシアンの光/背後に魔法陣の後光)、色(黒曜石・深藍・金・淡シアン＋キャラごとのアクセント)、
   シルエットの読みやすさ(小さく表示しても敵種が分かる)、数学モチーフの入れ方(例:素数=結晶の巨人、天秤=審判の像、確率=運命のサイコロの魔獣、
   関数=グラフを翼に持つ鳥、円=光輪をまとう聖獣… 数式や図形は「意匠」として自然に組み込み、文字は入れない)。
2. **パイロット画像を約10枚**生成する（画像生成機能を使う。使えなければその旨を docs/enemy-pilot/README.md に明記して中止）:
   - 雑魚(unit): アート型 calc, balance, prime, geo の4体（種ごとの見本）
   - 章ボス(chapterBoss): 中1の章ボス3体（章ごとに全く別のデザイン。monsters.js から該当を選ぶ）
   - 最終ボス(finalBoss): 中1の魔王1体（最も威厳のあるデザイン）
   - 小単元ボス(unitSmallBoss): 2体（章ボスとは別デザインで、格下の威厳）
3. 仕様: 各512×512、**背景は透過**（生成が単色背景なら、スクリプトで確実に切り抜いて透過webpにする。縁のフリンジ/にじみが無いこと）、
   全身が枠内に収まり、余白は約6%、正面〜やや斜めの3/4ビュー、足元に影は入れない(ゲーム側で付ける)。
   `docs/enemy-pilot/<monsterId>.webp`（monsterId は monsters.js の id）。あわせて 96×96 のサムネ版 `<id>_small.webp` も。
4. 確認用に `docs/enemy-pilot/index.html`（暗い背景に全パイロット画像を並べ、実寸/縮小表示を確認できる静的ページ）と
   `docs/enemy-pilot/README.md`（絵柄ガイド、各キャラのコンセプト一行、生成方法、透過処理の方法、課題）を作る。
5. **全240体への展開計画** `docs/ENEMY_DESIGN_PLAN.md`: 種類別の必要枚数、ボス152体を全員別デザインにするためのコンセプト付与の方針
   （章/単元のテーマ→モチーフ→シルエット差別化の表）、想定の作業量、フェーズ分け案、コード側で必要な変更点
   （画像の解決を id 単位に拡張する方法。既存の art型＋hue の仕組みを壊さず、id 専用画像があればそれを優先するフォールバック方式）を書く。
