# 協力プレイ「裏ボス」21体の敵画像

数学ラボ3（空中学園 ASTRA ACADEMY）の協力プレイに出てくる、**各章の裏ボス**。通常のボスよりはるかに強い、イベント級の存在。
絵柄は既存の敵と同じ（`docs/enemy-work/pilot-sheet.png` と `docs/enemy-work/BRIEF_CHAPTER.md` の「絵柄（凍結）」を必ず読む）：
少し写実的で重厚なダークファンタジー。黒曜石・深藍の装甲・古金・淡シアンの発光。章のアクセント色を主役にする。

## 通常のボスとの違い（重要）
- **一回り以上大きく、威厳と圧がある**（王・神・災厄クラス）。後光・浮遊する装飾・多重の輪・翼・冠などで「格が違う」ことが一目で分かる。
- **21体すべて別シルエット**。既存の敵（`docs/enemy-work/ledger/*.md`）とも被らない。台帳を読んで系統（鳥・亀・蛇・人型・機械・結晶・多脚…）の重複を避ける。
- 各体の名前・一言の説明（manifest.json の name/desc）と、その章のテーマ（章名は chapterId から。例 c1=正負、g2c3=一次関数）を造形のモチーフに反映する。
- 画像内に文字・数字・数式・ロゴ・透かしは入れない。血・残酷表現は禁止。オリジナル（既存作品に似せない）。

## 出力
- 透明背景・全身・正面〜3/4・床影なし・余白約6%・1体のみ。
- 生成PNGは `python3 docs/enemy-work/process_png.py <PNG> <ID>` で処理（→ `src/third/assets/monsters/by-id/full|small/<ID>.webp`）。
- 全部そろったら `docs/raid-art/sheets/<バッチ名>.png` にコンタクトシートを作って見比べ、崩れ・文字混入・被りは作り直す（最大2回）。
- 編集してよいのは `docs/raid-art/`、`src/third/assets/monsters/by-id/` だけ。ソースコードは触らない。
